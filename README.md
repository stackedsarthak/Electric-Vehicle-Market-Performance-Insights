# ⚡ Electric Vehicle Market Performance & Insights

An interactive EV data analytics project featuring **9 Tableau visualizations, an interactive dashboard, a Tableau Story, and a live web application.**

## 📌 Project Overview

This project focuses on analyzing Electric Vehicle (EV) data to understand manufacturer performance, vehicle types, electric range, geographical distribution, and market trends.

The analysis is performed using Tableau Public, and the visualizations are presented through a responsive website.

## 🎯 Problem Statement

How can electric vehicle data be analyzed and visualized to understand EV market trends, manufacturer performance, vehicle range, and geographical distribution?

## 📊 Tableau Visualizations

The project includes 9 visualizations:

1. EV Count by Manufacturer
2. EV Count by Vehicle Type
3. Average Electric Range by Manufacturer
4. EV Count by Model Year
5. EV Count by State
6. CAFV Eligibility Distribution
7. Average Electric Range by Model Year
8. Top 10 EV Manufacturers
9. EV Models by Manufacturer

## 📈 Expected Outcomes

- Understand EV distribution by manufacturer.
- Compare different EV types.
- Analyze electric vehicle range.
- Explore state-wise EV distribution.
- Identify trends across model years.
- Understand CAFV eligibility distribution.

## ⚠️ Data Limitations

- Analysis depends on the available dataset.
- Vehicle count should not be interpreted as sales.
- Results are limited to the dataset's coverage and available fields.
